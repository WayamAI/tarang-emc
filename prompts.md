# Tarang 3D icon prompts

Copy-paste these into Flow, Midjourney, or Ideogram. Every prompt is built for **Tarang**, the Wayam AI EMC foresight console for appliance design, not generic electronics clipart.

Use them on page headers, KPI tiles, the interference-path nodes, the workspace inspector, agent observation cards and empty states. Do **not** put readable text, standard numbers, part numbers, lab names or brand marks in the render. The Lucide icons in the sidebar stay; these are the dimensional marks for cards and empty surfaces.

## How to generate

- One subject per image. Do not collage several of these into one render.
- Export **square PNG**, transparent if the tool allows, else `#101010` background so it sits on `bg-container`.
- Target **1024²**; the UI displays them at 20 to 44px on tiles, inspector rows and headers.
- If the model adds text, rerun with `no text, no letters, no numbers` at the end.
- If the orange drifts toward red or gold, append `hue locked to #FF7B1C, not red, not amber`.
- Do not generate test-lab, appliance or semiconductor brand marks. Prompts 12, 13 and 32 are generic instruments, not a named model.
- Until a render exists, the app shows the Lucide glyph registered for that id in `src/lib/marks.ts`, so a partial set is safe to drop in.
